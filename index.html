How to install
  1. Download script.json and place it in your themes folder (create the folder if needed):
    • macOS / Linux: ~/.config/zed/themes/
    • Windows: %APPDATA%\Zed\themes
  2. In Zed's command palette, run theme selector: toggle and choose Script Dark or Script Light. Restart Zed if they do not appear.
  3. Run zed: open settings file and merge the settings below into your existing user settings. These follow your system appearance and enable the bracket colours.
settings.json
{
  "theme": {
    "mode": "system",
    "dark": "Script Dark",
    "light": "Script Light"
  },
  "colorize_brackets": true
}
